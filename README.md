# Movies
The app shows a list of movies, their details (fetched from themoviedb API). Additionally, a user can sort list by selected option, search movie by a name. Also offline mode is here, downloaded movies are cached with their posters.

Movies written app in Swift 5 demonstrating MVP+R, using UIKit with programmatic layout, Alamofire for networking.

# How to run 
REQUIREMENTS 
  XCode 16.0+
  iOS 15.0+

GETTING STARTED
  1. Clone this repository.
  2. Open the .xcworkspace file and you are ready to go.
